# Benim-futbol-hayat-m
Benim Futbol Hayatım, oyuncuların 15 yaşında futbol kariyerine başladığı, kendi futbolcusunu oluşturabildiği, kulüplerde oynayabildiği ve gerçekçi 3D maçlara katılabildiği bir futbol kariyer oyunudur. Transferler, özel arkadaş ligleri, çevrim içi maçlar, antrenmanlar ve milli takım kariyeri içerir.
